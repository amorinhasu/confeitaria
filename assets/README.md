# Assets visuais do Momozin

Pasta reservada para imagens, GIFs e banners do bot.

> Observação: o Discord só exibe imagens de embed por URL pública ou anexos. Para deploy simples, mantenha os arquivos aqui como fonte organizada e configure futuramente `ASSETS_BASE_URL` apontando para o local público onde esses arquivos forem hospedados.

## Estrutura

- `visuals/panel/` — banners do painel principal.
- `visuals/manual/` — banners e imagens do manual.
- `visuals/recados/` — imagens/GIFs de recados.
- `visuals/memorias/` — imagens de memórias.
- `visuals/cine/` — banners do CineMomozin.
- `visuals/playlist/` — imagens/GIFs da playlist.
- `visuals/estudos/` — imagens de estudos do Kaiki.
- `visuals/momocoins/` — imagens de MomoCoins.
- `visuals/mimos/` — imagens da loja de mimos.
- `visuals/perfil/` — banners do perfil do casal.
- `visuals/feedback/` — imagens/GIFs de erro e sucesso.
